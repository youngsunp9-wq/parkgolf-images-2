<p style="font-size: 17px; line-height: 1.85;" data-ke-size="size16">"대주주는 웃돈 받고 팔았는데, 내 주식은 왜 그대로지?" 회사 주인이 바뀔 때마다 소액주주들이 품어 온 불만입니다. 이 불만을 풀겠다는 제도가 바로 <b>의무공개매수</b>입니다.</p>

<h2 style="border-left: 6px solid #1d4ed8; padding: 4px 0 4px 12px; margin: 40px 0 16px 0;" data-ke-size="size26">의무공개매수 뜻, 한 문장으로</h2>
<p style="font-size: 17px; line-height: 1.85;" data-ke-size="size16">의무공개매수는 <b>회사 경영권을 사는 사람이 대주주 지분만 사지 말고, 일반 주주에게도 같은 가격으로 주식을 사겠다고 공개적으로 제안해야 하는 제도</b>입니다.</p>
<p style="font-size: 17px; line-height: 1.85;" data-ke-size="size16">여기서 "공개매수"는 증권시장 밖에서 "언제까지, 얼마에, 몇 주를 사겠다"고 미리 알리고 주주들로부터 주식을 사들이는 방법입니다. 지금도 공개매수는 할 수 있지만 <b>의무</b>는 아닙니다.</p>
<p style="font-size: 17px; color: #1d4ed8; margin: 22px 0 0 0;" data-ke-size="size16"><b>그렇다면 지금은 왜 문제가 될까요? 핵심은 "웃돈"입니다.</b></p>
<h2 style="border-left: 6px solid #1d4ed8; padding: 4px 0 4px 12px; margin: 40px 0 16px 0;" data-ke-size="size26">경영권 프리미엄이란</h2>
<p style="font-size: 17px; line-height: 1.85;" data-ke-size="size16">경영권을 넘길 때 대주주 지분은 보통 시장 가격보다 비싸게 팔립니다. 회사를 마음대로 운영할 권리까지 함께 넘기기 때문인데, 이 웃돈을 <b>경영권 프리미엄</b>이라고 합니다.</p>
<div style="background: #eff6ff; border-left: 6px solid #1d4ed8; border-radius: 8px; padding: 16px 20px; margin: 20px 0;"><p style="margin: 0 0 8px 0; font-weight: bold; color: #1d4ed8;" data-ke-size="size16">💡 쉬운 예시 (가정)</p><p style="margin: 0; font-size: 16px; line-height: 1.9;" data-ke-size="size16">주가가 1만 원인 회사의 대주주가 지분 30%를 주당 1만 5천 원에 넘긴다고 해 봅시다.<br />· 대주주: 주당 5천 원의 웃돈을 받고 나감<br />· 소액주주: 웃돈 없음. 새 주인이 마음에 안 들어도 시장에서 1만 원 언저리에 팔 수밖에 없음<br />의무공개매수가 있으면 새 주인은 일반 주주에게도 1만 5천 원에 사겠다고 제안해야 합니다.</p></div>
<p style="font-size: 17px; line-height: 1.85;" data-ke-size="size16">자본시장연구원은 간담회 발제에서 이 구조를 한국 증시 저평가의 원인 가운데 하나로 꼽았습니다.</p>
<p style="font-size: 17px; color: #1d4ed8; margin: 22px 0 0 0;" data-ke-size="size16"><b>그렇다면 일반 주주 주식은 얼마나 사 줘야 할까요? 여기서 의견이 크게 갈립니다.</b></p>

<p style="font-size: 17px; line-height: 1.85;" data-ke-size="size16">보류 이유로는 "50%+1주로는 소액주주 보호가 부족하다"는 비판과, 인수자가 대주주 지분을 먼저 산 뒤 나머지만 공개매수하는 <b>선행매수 허용</b> 문제가 꼽혔습니다. 반대로 인수합병(M&amp;A) 시장이 위축될 수 있다는 걱정도 나옵니다.</p>
<p style="font-size: 17px; color: #1d4ed8; margin: 22px 0 0 0;" data-ke-size="size16"><b>양쪽 주장이 팽팽한 만큼, 개인 투자자에게 실제로 무엇이 달라질지 따져 볼 필요가 있습니다.</b></p>
<h2 style="border-left: 6px solid #1d4ed8; padding: 4px 0 4px 12px; margin: 40px 0 16px 0;" data-ke-size="size26">개인 투자자에게 달라지는 점</h2>
<ul style="font-size: 17px; line-height: 1.9;"><li>인수합병 소식이 나왔을 때 <b>내 주식도 대주주와 같은 값에 팔 기회</b>가 생깁니다</li><li>다만 50%+1주 방식이면 응모한 주식이 <b>일부만</b> 팔릴 수 있습니다</li><li>인수 비용이 늘어 M&amp;A 자체가 줄면, 반대로 "인수 기대감" 같은 호재가 줄어들 수도 있습니다</li><li>시행은 법 공포 1년 뒤라, 당장 진행 중인 거래에는 적용되지 않습니다</li></ul>
<p style="font-size: 17px; line-height: 1.85;" data-ke-size="size16">특히 대주주 지분이 30~40%대인 회사가 많은 한국에서는 경영권 거래가 대주주끼리 장외에서 이뤄지는 경우가 많아, 소액주주가 거래 사실을 뒤늦게 아는 일도 흔했습니다.</p>
<p style="font-size: 17px; color: #1d4ed8; margin: 22px 0 0 0;" data-ke-size="size16"><b>이 제도는 사실 처음이 아닙니다. 한국에는 한 번 있다가 사라진 적이 있습니다.</b></p>
<h2 style="border-left: 6px solid #1d4ed8; padding: 4px 0 4px 12px; margin: 40px 0 16px 0;" data-ke-size="size26">예전에도 있었던 제도</h2>
<p style="font-size: 17px; line-height: 1.85;" data-ke-size="size16">의무공개매수는 1997년 한국에 도입됐다가 외환위기 직후인 1998년, 기업 구조조정과 M&amp;A를 막는다는 이유로 폐지됐습니다. 그래서 이번 법안은 "<b>28년 만의 재도입</b>"으로 불립니다.</p>
<p style="font-size: 17px; line-height: 1.85;" data-ke-size="size16">영국·독일·일본 등 여러 나라는 이미 비슷한 제도를 두고 있어, 한국만 소액주주 보호가 약하다는 지적이 꾸준히 나왔습니다.</p>
<p style="font-size: 17px; line-height: 1.85;" data-ke-size="size16">다시 도입되면 이번에는 상장사 경영권 거래가 훨씬 투명해질 것이라는 기대가 큽니다.</p>
<p style="font-size: 17px; color: #1d4ed8; margin: 22px 0 0 0;" data-ke-size="size16"><b>그럼 앞으로 무엇을 지켜보면 될까요?</b></p>

<p style="font-size: 17px; line-height: 1.85;" data-ke-size="size16"><b>Q. 의무공개매수는 지금 시행 중인가요?</b><br />A. 아닙니다. 법안이 국회 본회의 직전 보류된 상태이고, 통과되더라도 공포 1년 뒤 시행하는 안입니다.</p>
<p style="font-size: 17px; line-height: 1.85;" data-ke-size="size16"><b>Q. 공개매수에 응하면 내 주식이 다 팔리나요?</b><br />A. 50%+1주 방식에서는 응모한 주식이 많으면 비율대로 나눠 사 주기 때문에 일부만 팔릴 수 있습니다.</p>
<p style="font-size: 17px; line-height: 1.85;" data-ke-size="size16"><b>Q. 경영권 프리미엄은 왜 생기나요?</b><br />A. 회사를 운영할 권리까지 함께 넘기기 때문에 대주주 지분은 시장 가격보다 비싸게 거래되는 경우가 많습니다.</p>
<p style="font-size: 17px; line-height: 1.85;" data-ke-size="size16"><b>Q. 100% 방식과 무엇이 다른가요?</b><br />A. 100% 방식은 남은 주주가 원하면 전부 사 줘야 해 소액주주 보호가 더 강하지만, 인수 비용이 크게 늘어납니다.</p>
